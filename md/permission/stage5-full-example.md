# Stage 5：完整权限实战

## 学习目标

- 综合运用前 4 个阶段的知识
- 模拟真实后台的权限控制
- 观察角色切换时的全维度联动

## 功能覆盖

| 维度 | 控制方式 | 表现 |
|------|----------|------|
| 路由级 | 菜单可见性（已过滤） | 无权限的菜单不显示 |
| 菜单级 | 侧边栏导航 | 无权限的菜单暗色灰显 |
| 按钮级 | v-permission 指令 | 无权限按钮消失 |
| 组件级 | v-permission / v-if | 整个面板不渲染 |
| 行级 | 后端数据过滤 | 只返回有权限的数据行 |
| 字段级 | 后端脱敏 | 敏感字段显示 `****` |
| 模式级 | :disabled 绑定 | 无权限时按钮置灰 |
