# 应用规模化

Vue 3 应用从原型到生产需要的工程化实践。

## 目录

| 主题 | 路由 | 说明 |
|------|------|------|
| 单文件组件 (SFC) | `/sfc` | `.vue` 文件结构、script setup、scoped CSS |
| 工具链 | `/toolchain` | Vite、TypeScript、vue-tsc、ESLint、Prettier |
| 路由 | `/routing` | SPA 路由原理概览 → 详细教程 `/vue-router` |
| 状态管理 | `/state` | 状态管理方案对比概览 → 详细教程 `/pinia` |
| 测试 | `/testing` | Vitest、Vue Test Utils、Playwright |
| 服务端渲染 (SSR) | `/ssr` | SSR 原理、Hydration、Nuxt、SSG |
